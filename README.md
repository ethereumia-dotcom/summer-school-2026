# Summer School 2026 — Climbing MVP Delivery

Выбранный бриф: **Скалодром «Вертикаль»**.

## Скоуп

Текущая поставка относится только к роли **Клиент**:

- клиентское мобильное приложение;
- API-контракт для клиентского приложения;
- просмотр тренировок;
- фильтрация тренировок;
- просмотр деталей тренировки;
- выбор снаряжения;
- создание и просмотр записи;
- обработка отменённого слота;
- базовые тест-кейсы.

Вне скоупа:

- админка;
- интерфейс инструктора;
- создание расписания;
- управление зонами, форматами и инструкторами;
- внутренняя реализация backend;
- онлайн-оплата.

## Что подготовлено

- MVP requirements.
- User stories и основные сценарии.
- Дизайн-бриф экранов.
- Техническая спецификация клиентского приложения.
- OpenAPI-контракт.
- 3 feature-документа.
- 3 bug-документа.
- Тест-кейсы.
- Результат ручной проверки сборки.

## Что изменено в коде

В клиентском коде применены правки под домен скалодрома:

- пользовательские тексты «Волна» заменены на «Вертикаль»;
- старые SUP-термины заменены на термины скалодрома;
- список и вкладка «Прогулки» переименованы в «Тренировки»;
- empty state обновлён на «Пока нет доступных тренировок»;
- фильтр «Эта неделя» заменён на «7 дней»;
- расчёт `NextSevenDays` исправлен на ближайшие 7 дней;
- отменённый слот больше не открывается для записи;
- для отменённого слота показывается статус «Отменена скалодромом».
