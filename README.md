# Летняя школа — бриф «Скалодром»

Короткая сдача по выбранному брифу «Скалодром Вертикаль»: аналитика, требования, дизайн-бриф, технический дизайн, API-контракт, ТЗ приложения, документы по 3 фичам и 3 багам.

## Что внутри

- `01-analysis/0-customer-brief/` — исходный бриф и зафиксированные ограничения.
- `01-analysis/1-elicitation/` — вопросы к заказчику, ответы, доменная модель и границы скоупа.
- `01-analysis/2-requirements/` — BR/FR/NFR, user stories и use cases.
- `01-analysis/3-design-brief/` — foundations, экраны и шторки для макетирования.
- `01-analysis/4-design/` — модель данных и sequence-диаграммы.
- `01-analysis/api/` — OpenAPI-контракт клиентского API.
- `01-analysis/5-mobile-app-spec/` — карта экранов и переиспользуемые логики.
- `01-analysis/6-implementation/` — отчёты по 3 фичам, 3 багам и ручные тест-кейсы.

## Скоуп

В текущей поставке делается только клиентское мобильное приложение и API для него. Backend, админка, интерфейс инструктора, создание расписания, редактирование слотов и гарантия отсутствия двойных броней находятся вне скоупа клиентского приложения.

## Что подготовлено

Фичи:

1. дефолтный список тренировок на ближайшие 7 дней и empty state;
2. фильтры тренировок под домен скалодрома;
3. выбор своего или прокатного снаряжения при записи.

Баги:

1. отменённый слот не должен открываться для записи;
2. preset «Эта неделя» не должен подменять требование «ближайшие 7 дней»;
3. пользовательские тексты домена «Волна» нужно заменить на домен «Скалодром».
   
## Проверка перед сдачей

1. Применить изменения в ветке `feature/client`.
2. Запустить проект и пройти тест-кейсы из `01-analysis/6-implementation/test-cases.md`.
3. Сделать отдельные git-коммиты по фичам/багам или минимум зафиксировать изменения в одном понятном коммите.
4. Сдавать ссылку на репозиторий/ветку или архив репозитория с кодом и `.md`-документами.

- Документы по 3 фичам и 3 багам добавлены.
- Кодовые правки клиента применены.
- Клиентский shared-модуль собран командой `.\gradlew.bat :shared:compileDebugKotlinAndroid`.
- Результат проверки зафиксирован в `01-analysis/6-implementation/manual-test-run.md`.
