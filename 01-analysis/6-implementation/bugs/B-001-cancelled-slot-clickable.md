# B-001. Отменённая тренировка открывается для записи

## Симптом

Карточка тренировки была кликабельной, если у слота `freeSeats > 0`, даже когда `status = cancelled`.

## Требования

- FR-007: клиент открывает карточку доступной тренировки.
- FR-008: отменённый слот недоступен для повторной записи.
- R-008 из уточнения: повторная запись на отменённый слот запрещена.

## Причина

В `SlotListScreen.kt` доступность карточки вычислялась только по количеству свободных мест:

    val canOpen = slot.freeSeats > 0

Статус слота не учитывался.

## Что исправлено

Доступность карточки теперь учитывает статус:

    val canOpen = slot.status == SlotStatus.Scheduled && slot.freeSeats > 0

Для отменённой тренировки показывается пользовательский статус:

    Отменена скалодромом

## Использованные промпты

1. «Найди баг в карточке слота: отменённый слот с freeSeats > 0 всё ещё открывает форму записи».
2. «Исправь доступность карточки так, чтобы учитывался SlotStatus.Scheduled».
3. «Добавь понятный текст для отменённого слота в UI».

## Ручная проверка

- Подготовила/нашла слот со статусом `cancelled` и `freeSeats > 0`.
- Открыла список тренировок.
- Проверила, что карточка показывает «Отменена скалодромом».
- Нажала на карточку — форма записи не открылась.
- Проверила, что обычный `scheduled` слот со свободными местами открывается.
