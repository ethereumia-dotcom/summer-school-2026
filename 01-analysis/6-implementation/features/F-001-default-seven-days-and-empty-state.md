# F-001. Дефолтный список тренировок на 7 дней и empty state

## Цель

Сделать так, чтобы клиент при первом открытии видел тренировки на ближайшие 7 дней, а при отсутствии расписания получал понятное сообщение.

## Требования

- FR-001: клиент видит список тренировок на ближайшие 7 дней по умолчанию.
- FR-002: если расписания нет, показан empty state.
- R-027 из уточнения брифа: по умолчанию клиенту показываются слоты на ближайшие 7 дней от текущего момента.
- Если расписания нет, показывается empty state «Пока нет доступных тренировок».

## Что сделано

- В `SlotListState` дефолтные фильтры заменены на `defaultSlotFilters()`.
- Дефолтный preset заменён на `NextSevenDays`.
- Сброс фильтров возвращает период ближайших 7 дней.
- Empty state переименован с «прогулок» на «тренировок».

## Использованные промпты

1. «Проанализируй бриф “Скалодром” и выдели минимальные требования к списку тренировок для MVP».
2. «Найди в клиенте место, где хранится состояние фильтров списка слотов, и сделай дефолтный период ближайшие 7 дней».
3. «Проверь текст empty state для пустого расписания и адаптируй его под домен скалодрома».

## Ручная проверка

- Открыл список тренировок.
- Проверил, что фильтр по умолчанию соответствует 7 дням.
- Проверил empty state при пустом ответе backend.
- Открыл фильтры, нажал «Сбросить», применил — период снова 7 дней.
