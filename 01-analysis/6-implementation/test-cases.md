# Тест-кейсы — MVP «Скалодром Вертикаль»

## TC-001. Список тренировок открывается с периодом 7 дней

**Предусловия:** backend запущен, есть тренировки в ближайшие 7 дней.

**Шаги:**
1. Открыть приложение.
2. Перейти на экран списка тренировок.

**Ожидаемый результат:**
Показан список тренировок на ближайшие 7 дней. На экране заголовок «Тренировки», в фильтрах период обозначен как «7 дней», а не «Эта неделя».

## TC-002. Пустое расписание

**Предусловия:** backend возвращает пустой список для дефолтного периода.

**Шаги:**
1. Открыть список тренировок.

**Ожидаемый результат:**
Показано сообщение «Пока нет доступных тренировок».

## TC-003. Фильтр по формату

**Предусловия:** есть тренировки разных форматов.

**Шаги:**
1. Открыть фильтры.
2. Выбрать формат для новичков.
3. Нажать «Применить».

**Ожидаемый результат:**
В списке только тренировки выбранного формата.

## TC-004. Фильтр без результатов

**Предусловия:** есть фильтр, под который нет тренировок.

**Шаги:**
1. Открыть фильтры.
2. Выбрать условия без результатов.
3. Нажать «Применить».

**Ожидаемый результат:**
Показано «Нет слотов по условиям» и кнопка «Фильтры».

## TC-005. Сброс фильтров

**Предусловия:** применён фильтр.

**Шаги:**
1. Открыть фильтры.
2. Нажать «Сбросить».
3. Нажать «Применить».

**Ожидаемый результат:**
Список снова показывает дефолтный период 7 дней.

## TC-006. Открытие доступной тренировки

**Предусловия:** есть тренировка `scheduled` со свободными местами.

**Шаги:**
1. Нажать на карточку тренировки.

**Ожидаемый результат:**
Открывается экран деталей/оформления записи.

## TC-007. Отменённая тренировка не открывается для записи

**Предусловия:** backend возвращает слот `cancelled` со свободными местами больше 0.

**Шаги:**
1. Открыть список тренировок.
2. Найти отменённую тренировку.
3. Нажать на карточку.

**Ожидаемый результат:**
Карточка не открывает форму записи. На карточке видно «Отменена скалодромом».

## TC-008. Запись на одно место со своим снаряжением

**Предусловия:** есть доступная тренировка.

**Шаги:**
1. Открыть тренировку.
2. Оставить 1 место.
3. Выбрать «Своё».
4. Нажать «Записаться».

**Ожидаемый результат:**
Бронь создана, показан экран «Вы записаны».

## TC-009. Запись с прокатным снаряжением

**Предусловия:** есть доступная тренировка и свободный прокат.

**Шаги:**
1. Открыть тренировку.
2. Выбрать 1 место.
3. Выбрать «Прокат».
4. Нажать «Записаться».

**Ожидаемый результат:**
Бронь создана, итоговая цена включает прокат.

## TC-010. Нельзя выбрать прокат сверх доступного фонда

**Предусловия:** у слота доступен 1 прокатный комплект.

**Шаги:**
1. Открыть форму записи.
2. Выбрать 2 места.
3. Попробовать выбрать прокат для обоих мест.

**Ожидаемый результат:**
Прокат можно выбрать только для 1 участника. Лишний выбор не применяется.

## TC-011. Backend отказал из-за отсутствия мест

**Предусловия:** слот был доступен, но места закончились до отправки формы.

**Шаги:**
1. Открыть форму записи.
2. Нажать «Записаться».

**Ожидаемый результат:**
Показано понятное сообщение «В этом слоте больше нет свободных мест» или аналогичное сообщение API.

## TC-012. Мои записи — пустой список

**Предусловия:** у пользователя нет записей.

**Шаги:**
1. Открыть «Мои записи».

**Ожидаемый результат:**
Показано «У вас пока нет записей» и кнопка для записи.

## TC-013. Мои записи — активная запись

**Предусловия:** у пользователя есть активная будущая бронь.

**Шаги:**
1. Открыть «Мои записи».
2. Перейти на вкладку «Предстоящие».

**Ожидаемый результат:**
Запись отображается со статусом «Активна».

## TC-014. Мои записи — отмена скалодромом

**Предусловия:** у пользователя есть бронь на слот со статусом `cancelled`.

**Шаги:**
1. Открыть «Мои записи».

**Ожидаемый результат:**
Запись не пропала и отображается со статусом «Отменена скалодромом».

## TC-015. Ошибка сети при загрузке списка

**Предусловия:** backend недоступен.

**Шаги:**
1. Открыть список тренировок.

**Ожидаемый результат:**
Показана ошибка «Не удалось загрузить» и кнопка «Обновить».
