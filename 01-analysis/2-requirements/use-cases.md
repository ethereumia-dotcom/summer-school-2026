# Use cases

## UC-001. Просмотр списка слотов

**Актор:** клиент.  
**Предусловие:** backend отдаёт расписание.  
**Основной поток:** приложение запрашивает `listSlots` на ближайшие 7 дней, отображает список или empty state.  
**Альтернатива:** ошибка сети → error state с повтором.

## UC-002. Фильтрация слотов

Клиент открывает фильтр, выбирает даты/формат/инструктора/доступность, применяет фильтр. Приложение вызывает `listSlots` с параметрами.

## UC-003. Создание брони

Клиент открывает карточку доступного слота, выбирает количество мест и снаряжение, отправляет форму. Приложение вызывает `createBooking`. При `201` показывает успех, при `409 slot_full` показывает ошибку и предлагает обновить список.

## UC-004. Отмена своей брони

Клиент открывает запись, нажимает «Отменить», подтверждает действие. Приложение вызывает `cancelBooking`. Итоговый статус возвращает backend.

## UC-005. Отмена скалодромом

Backend возвращает бронь со статусом `cancelled_by_club` и причиной. Приложение не удаляет запись, показывает статус «Отменена скалодромом» и не даёт записаться на отменённый слот.
