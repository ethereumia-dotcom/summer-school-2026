# LOGIC-003-price. Расчёт цены

## Назначение

Переиспользуемая логика мобильного приложения.

## Входные данные

seats_count, rental_count, price, rental_price.

## Правила

- Не дублировать backend-инварианты, которые должны проверяться атомарно на сервере.
- До отправки формы можно делать пользовательскую валидацию для лучшего UX.
- При конфликте с backend доверяем ответу API.
