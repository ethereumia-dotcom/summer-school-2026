# Доменное описание — «Скалодром Вертикаль»

## Акторы

| Актор | Роль в текущем скоупе |
|---|---|
| Клиент | Пользуется мобильным приложением, просматривает слоты, создаёт и отменяет свои записи |
| Existing backend | Источник расписания, слотов, инструкторов, доступности и статусов |
| Инструктор | Вне текущего скоупа, уже имеет существующий интерфейс |
| Администратор/владелец | Вне текущего скоупа, уже имеет админку |

## Сущности

| Сущность | Описание | Mutable для клиента? |
|---|---|---|
| Client | пользователь приложения | да: авторизация/контактные данные через API |
| Slot | конкретная тренировка во времени | нет, read-only |
| TrainingFormat | формат/зона тренировки | нет, read-only |
| Instructor | инструктор тренировки | нет, read-only |
| Booking | запись клиента на слот | да: создать/отменить свою запись |
| EquipmentChoice | выбор своего/прокатного снаряжения | да: при создании брони |
| CancellationReason | причина отмены скалодромом | нет, read-only |

## Границы скоупа

### В скоупе MVP

- список доступных слотов;
- фильтры по дате, формату, инструктору и свободным местам;
- карточка слота;
- создание брони;
- выбор снаряжения;
- просмотр своих броней;
- отображение отмены скалодромом;
- отмена своей брони.

### Вне скоупа MVP

- создание расписания;
- редактирование слотов;
- интерфейсы инструктора и администратора;
- онлайн-оплата;
- программа лояльности;
- публичные рейтинги инструкторов;
- серверная транзакционность и SLA.

## Глоссарий

- **Слот** — тренировка с конкретным временем начала, форматом, инструктором и количеством свободных мест.
- **Бронь** — запись клиента на слот.
- **Прокатный комплект** — снаряжение, которое выдаётся клиенту на тренировку.
- **Отмена скалодромом** — отмена тренировки организатором или из-за профилактики/проверки снаряжения.
- **Поздняя отмена** — отмена клиентом слишком близко ко времени начала; итоговые последствия определяет backend.
