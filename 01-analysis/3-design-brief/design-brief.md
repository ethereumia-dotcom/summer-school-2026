# Дизайн-бриф — клиентское приложение «Скалодром Вертикаль»

## Цель дизайна

Сделать мобильный клиентский путь, в котором посетитель скалодрома без переписки выбирает тренировку, бронирует место и видит свои записи.

## Экраны MVP

| ID | Экран/шторка | Покрывает FR |
|---|---|---|
| SCR-001 | Список тренировок | FR-001, FR-002 |
| BS-001 | Фильтры слотов | FR-003–FR-006 |
| SCR-002 | Карточка тренировки | FR-007, FR-008 |
| SCR-003 | Форма записи | FR-009–FR-013, FR-016 |
| SCR-004 | Успешная запись | FR-009 |
| SCR-005 | Мои записи | FR-014, FR-017 |
| SCR-006 | Детали записи | FR-014, FR-015, FR-017 |
| BS-002 | Подтверждение отмены | FR-015 |
| BS-003 | Ошибка отсутствия мест | FR-016 |

## Ключевые состояния

- Нет тренировок: «Пока нет доступных тренировок».
- Нет результатов фильтра: «Нет слотов по условиям».
- Отменённая тренировка: бейдж «Отменена скалодромом», CTA записи скрыт/disabled.
- Нет записей: «Выберите тренировку и оформите бронь».

## Гейт

Нет «осиротевших» экранов: каждый экран связан с FR и сценарием. Дизайн не добавляет новых backend-операций вне API-контракта.
