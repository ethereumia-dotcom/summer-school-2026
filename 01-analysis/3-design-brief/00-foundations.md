# Foundations для дизайна

## Навигация

- Основные разделы MVP: `Тренировки`, `Мои записи`.
- Главный путь: `Тренировки → Карточка тренировки → Форма записи → Успех → Мои записи`.

## Состояния экранов

Для экранов со списками и API-запросами должны быть описаны состояния:

- loading;
- content;
- empty;
- error;
- success/result, если применимо.

## Общие UI-правила

- Не показывать отменённый слот как доступный.
- Не использовать терминологию проекта «Волна»: прогулки, доски, маршруты SUP.
- Доменная терминология: тренировка, формат, инструктор, снаряжение, прокатный комплект.
- CTA должен быть один главный на экран.
- Ошибки backend переводятся в пользовательские сообщения.

## Accessibility

- Контраст текста и кнопок — не ниже WCAG AA.
- Все интерактивные элементы имеют понятный label.
- Disabled-состояние должно быть визуально отличимо и объяснено текстом.
